This Week 5 final project integrates the data-science skills developed throughout the previous weeks into a single, documented machine-learning workflow. It covers problem definition, dataset selection, data preparation, model development, validation, performance evaluation, visualization, error analysis, limitations, and strategic recommendations.

The project uses the Wisconsin Diagnostic Breast Cancer dataset bundled with scikit-learn. The dataset contains 569 observations and 30 numeric features. For consistent interpretation, malignant cases are designated as the positive class and benign cases as the negative class. The work is an educational model-comparison exercise and is not intended for medical diagnosis or clinical decision-making.

Two classification algorithms are trained and evaluated: Logistic Regression and a constrained Decision Tree. The data is divided into stratified training and test sets using a reproducible random seed. Preprocessing is handled within pipelines to reduce the risk of data leakage. Logistic Regression includes feature scaling, while the Decision Tree uses depth and leaf-size limits to control complexity. Five-fold cross-validation is performed on the training set, and the final comparison uses the held-out test set.

The report compares accuracy, precision, recall, F1-score, and ROC-AUC. It includes a model-performance chart, a confusion matrix, ROC curves, and a cross-validation visualization. The analysis explains the trade-offs between the models, highlights the importance of false-negative analysis, and discusses overfitting, threshold selection, dataset representativeness, and the limits of test-set metrics.

The final report also provides strategic recommendations, including retaining Logistic Regression as the educational baseline, conducting further error analysis, evaluating threshold trade-offs, and requiring independent validation before any real-world application. The accompanying Python script reproduces the model training and evaluation workflow and regenerates the visualizations.
